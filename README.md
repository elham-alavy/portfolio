# Elham Hasani Alavy — academic portfolio

Personal research website: https://elham-alavy.github.io/portfolio/

A static site with a responsive navigation menu, light and dark themes, and accessible section navigation. No build step or external font dependencies.

## Edit

- `index.html`: biography, research interests, projects, education, and contact links.
- `styles.css`: layout, colors, and responsive breakpoints.
- `script.js`: theme preference, mobile menu, and active navigation state.
- `assets/elham.jpg`: existing public GitHub portrait.

Run `python3 -m http.server 8765` in this directory and open http://localhost:8765.

GitHub Pages publishes the root of `main`. Push changes to that branch to update the live site.

The content is based on the existing public portfolio and profile README. Education entries describe fields and focus areas, not inferred degrees. Project repositories marked “Contributor access” have no public repository links. The separate GIS course portfolio remains at https://elham-alavy.github.io/.
